# Rous Coffee Management System (RCMS)

A relational database prototype built in Microsoft Access with VBA, designed for a
hypothetical coffee shop that needed better daily operations and visibility into
sales, inventory, and scheduling.

## What it does

- **Order management** — create orders, add items, calculate totals, update status
- **Inventory management** — track stock levels, prices, and low-stock alerts
- **Scheduling** — create shifts and assign employees
- **Reporting** — sales, inventory, and employee-hours reports for the owner
- **Role-based access** — separate views for employees, managers, and the owner

## Design process

The system was modeled from a business problem through to a working prototype:
a context diagram and DFD-0 to define scope, an ERD to design the data relationships,
and four core Access forms (Order Entry, Inventory, Schedule, Reports) to implement it.

## Files

- `RCMS.accdb` — the Access database (tables, forms, queries, reports)
- `RCMS_presentation.pptx` — full project write-up, including requirements,
  diagrams, prototype walkthrough, and deployment plan

Built for a Systems Analysis and Design course.
